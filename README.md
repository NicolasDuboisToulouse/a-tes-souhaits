# A Tes Souhaits

A tes souhaits est une application (web) permettant de gérer les souhaits d'un groupe d'amis / famille.

> [!WARNING]
> Les détails ci-dessous sont ceux de la dernière release.
> Une réécriture de l'application est en cours.

Fonctionnalités :
* Chacun peut définir sa liste de souhaits. Syntaxe avancée supportée tel que l'ajout de liens.
* Chacun peut voir la liste de souhait des autres. Il peut _réserver_ des souhaits.
* Chacun peut voir les souhaits _réservés_, sauf les siens !
* Support de listes partagées :
  * Liste appartenant à plusieurs personnes (par example un couple)
  * Liste que tout le monde peut modifier/réserver (par example, pour un jeune enfant)
* Interface d'administration :
  * Ajout de membres et de lise
  * Reset de mot de passe
  * (TBD) Effacer des souhaits d'une liste
* (TBD) Support de différents groupes d'amis: Chacun ne voit que les listes des groupes auquel il appartient.
